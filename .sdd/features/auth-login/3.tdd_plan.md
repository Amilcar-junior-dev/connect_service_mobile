# 3. Especificação Detalhada de Testes TDD: Autenticação (`auth-login`)

## 🧪 Estratégia de Mocks & Cobertura

- **`supabase.auth`**: Mock de `signInWithPassword`, `signUp`, `updateUser` e `exchangeCodeForSession`.
- **`companyService.getCompanyByOwner`**: Mockado para alternar entre empresa concluída (`onboarding_completed: true`) e não configurada (`null`).
- **`expo-router`**: Mock de `router.push` e `router.replace`.

---

## 📋 Especificação dos Cenários de Teste

### `[TDD-01]` Alternância de Visibilidade da Senha (`useLoginViewModel.test.ts`)
- **Objetivo:** Garantir que tocar no ícone `Eye` alterna o estado boolean `isPasswordVisible`.
- **Dado (Given):** ViewModel de login montada com `isPasswordVisible = false`.
- **Quando (When):** `togglePasswordVisibility()` é invocado.
- **Então (Then):** `isPasswordVisible` alterna para `true`, e no toque seguinte para `false`.

---

### `[TDD-02]` Login com Sucesso ➔ Empresa com Onboarding Concluído ➔ Navega para `/home`
- **Dado (Given):** `supabase.auth.signInWithPassword` retorna sessão válida e `companyService.getCompanyByOwner` retorna `{ onboarding_completed: true }`.
- **Quando (When):** `onSubmit()` é executado com credenciais válidas.
- **Então (Then):** `router.push` é chamado com `'/(private)/(tabs)/home'`.

---

### `[TDD-03]` Login com Sucesso ➔ Empresa sem Onboarding ➔ Navega para `/onboarding`
- **Dado (Given):** `supabase.auth.signInWithPassword` retorna sessão válida e `companyService.getCompanyByOwner` retorna `null`.
- **Quando (When):** `onSubmit()` é executado.
- **Então (Then):** `router.push` é chamado com `'/onboarding'`.

---

### `[TDD-04]` Alerta de Credenciais Inválidas
- **Dado (Given):** `supabase.auth.signInWithPassword` retorna erro `{ message: 'Credenciais inválidas' }`.
- **Quando (When):** `onSubmit()` é executado.
- **Então (Then):** `Alert.alert` exibe `'Erro ao entrar'`, e a navegação não é realizada.

---

### `[TDD-05]` Cadastro de Novo Usuário (`useRegisterViewModel.test.ts`)
- **Dado (Given):** Dados válidos de cadastro.
- **Quando (When):** `onSubmit()` é executado no registro.
- **Então (Then):** `supabase.auth.signUp` é chamado e a aplicação redireciona para `'/onboarding'`.

---

### `[TDD-06]` Redefinição de Senha via Deep Link (`resetPassword.viewModel.test.ts`)
- **Dado (Given):** A URL de abertura contém query param `code`.
- **Quando (When):** A ViewModel inicializa no `useEffect`.
- **Então (Then):** Invoca `supabase.auth.exchangeCodeForSession` com o código fornecido e permite atualizar a senha via `updateUser`.

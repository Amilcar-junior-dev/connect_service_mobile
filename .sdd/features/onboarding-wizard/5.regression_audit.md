# 5. Auditoria de Regressão: Onboarding Wizard

## 🔍 Mapeamento do Estado Anterior vs Alterações

### Telas e Fluxos Impactados:
1. **Login (`useLoginViewModel.ts`)**:
   - *Antes:* Navegava incondicionalmente para `/(private)/(tabs)/home`.
   - *Depois:* Consulta a tabela `companies` do Supabase. Se o onboarding não estiver concluído, direciona para `/onboarding`. Se concluído, direciona para `/home`.
2. **Cadastro (`useRegisterViewModel.ts`)**:
   - *Antes:* Navegava para `/home`.
   - *Depois:* Direciona para `/onboarding` para que o novo usuário configure seu estabelecimento no 1º acesso.
